# DF-site

Duistere-fantasy website **Grimwold** — statische site in HTML/CSS/JS.

## Pagina's
- `index.html` — Home (hero + teasers)
- `werelden.html` — De drie werelden van Grimwold
- `personages.html` — Vier personages
- `galerij.html` — Galerij met CSS-art
- `contact.html` — Contactformulier

## Structuur
- `css/style.css` — dark theme, responsive (mobiele nav vanaf 640px)
- `js/script.js` — mobiel menu, jaar in footer, scroll-reveal, formuliermelding

Lokaal bekijken: open `index.html` in de browser.
